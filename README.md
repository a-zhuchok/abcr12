**Объект тестирования:** Часы  
**Платформа:**  iOS  
**Охват:** будильники, таймер, секундомер, мировые часы

---

## Ключевые функции

**Будильник**

- создание будильника
- изменение времени
- удаление будильника
- включение и выключение без удаления

**Таймер**

- установка времени
- запуск и пауза
- сброс

**Секундомер**

- старт и стоп
- фиксация круга
- сброс

**Мировые часы**

- просмотр времени в разных города
- добавление и удаление города
- поиск города в списке
